# App de Parejas (AffiniScore Frontend)

## Descripción
Esta es la aplicación móvil de **AffiniScore**, diseñada para fortalecer la relación de pareja a través de dinámicas interactivas, retos de desconexión, y comunicación enriquecida.

> [!IMPORTANT]
> **Nota de Uso:** Esta aplicación está diseñada exclusivamente para interacciones de pareja y **no puede utilizarse de forma individual**. Para desbloquear y acceder a todas las funcionalidades del MVP (chat de pareja, retos, terapeuta IA, etc.), es necesario realizar el proceso de vinculación/emparejamiento con el otro usuario desde el flujo de configuración de la app.

## Estructura del Frontend
El código fuente de este directorio contiene la aplicación móvil construida utilizando **Ionic Framework** y **Angular**.

## Tecnologías Utilizadas
* Ionic Framework
* Angular
* TypeScript
* Capacitor (para empaquetado nativo de Android)
